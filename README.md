# NVIDIA Journey Dashboard

A personal progress tracker built as a standalone HTML/CSS/JS app
to document my 4-year journey from UGM Information Technology
toward AI/ML engineering.

## What this is
- Daily study log with categories, mood rating, and study hours
- Milestone tracker (24 milestones across 4 years)
- Pomodoro focus timer with session history
- XP and level system for gamified progress tracking

## What I learned building this
- HTML/CSS layout, CSS variables, CSS Grid
- Vanilla JavaScript: localStorage, DOM manipulation, Canvas API
- Pixel art background animation with requestAnimationFrame
- Studied and understood the full codebase including localStorage
  persistence, Canvas API animation, and JavaScript DOM manipulation

## Tech
HTML · CSS · Vanilla JavaScript · No frameworks · No dependencies

## Status
Active — used daily for study tracking
